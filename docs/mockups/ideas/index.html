UI ideas

Four one-page directions for the desktop app, each a different take on a dark, card-based look. All show the same run: Krautrock, tagging 7 of 12.

  1. Control room — pill nav, stat tiles, a confidence column in the track table, a library gauge
  2. Glass deck — a floating rail and track card, the run as a chart, recent changes as a ledger
  3. Sleeve wall — the art is the screen, a frosted player bar for the run, a side sheet for the track
  4. Bento — a grid of cards sized by importance, the folder's sleeves as the hero
  5. Wall and room — 1 and 3 combined: the library and an open folder as sleeve walls, a run as the control room, one chrome throughout
  6. Wall and room, icons — the same three screens with icons carrying the nav, filters, fields and key bar
